# Netflix Content Analysis | Excel, Power Query & Power BI

## 📌 Project Overview

This project analyzes the Netflix titles dataset to explore content distribution, country-wise availability, content ratings, release trends, and the overall composition of Movies and TV Shows.

The project combines **Excel, Power Query, and Power BI** to clean, transform, analyze, and visualize the data through an interactive dashboard.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze the distribution of Movies and TV Shows on Netflix
- Identify the most common content ratings
- Explore content availability by country
- Analyze content trends over time
- Understand the distribution of Netflix titles across different categories
- Create an interactive dashboard to communicate key insights

---

## 📂 Dataset

The project uses a Netflix titles dataset containing information about movies and TV shows available on the platform.

### Dataset Summary

- **Total Titles:** 8,801
- **Movies:** 6,127
- **TV Shows:** 2,674

The dataset includes information such as:

- Show ID
- Type
- Title
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed In
- Description

## 💡 Key Insights

The analysis highlighted several patterns within the Netflix dataset:

- **Movies account for the majority of titles**, with 6,127 Movies compared with 2,674 TV Shows.
- Movies represent approximately **69.6%** of the dataset, while TV Shows represent approximately **30.4%**.
- **TV-MA** is one of the most common content ratings in the dataset.
- The **United States** contributes the highest number of titles, followed by other major content-producing countries including **India**.
- The dataset contains a wide range of content categories and genres, reflecting the diversity of Netflix's content library.
